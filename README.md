# Orenji Data Science & AI

Site institucional responsivo da Orenji, preparado para publicação no GitHub Pages e Cloudflare Pages.

## Estrutura

- `index.html`: conteúdo e metadados do site.
- `assets/`: folha de estilos principal.
- `mobile-improvements.css`: ajustes responsivos e de acessibilidade.
- `brand-icons.css`: ícones da identidade visual.
- `site.js`: menu móvel e preparação da mensagem de contato.
- `robots.txt` e `sitemap.xml`: arquivos para indexação em buscadores.

O projeto é estático e não exige instalação ou etapa de build. Para testar localmente, abra o `index.html` ou use um servidor HTTP estático.
